# 科创人才消费贷款分类预测

本目录用于构建频繁支用预测（`y_freq`）和违约风险预测（`y_dq_risk`）模型。建模粒度为客户：账户级数据先按 `cst_id` 聚合为一客一行，再执行 LightGBM 训练、采样方法比较和最终测试评价。

## 文件说明

| 文件 | 作用 |
| --- | --- |
| `kechuang_potential_preprocessing.ipynb` | 主分析 notebook：配置数据与任务，调用预处理、分层划分数据集、训练 LightGBM、比较采样方法、输出最终测试与解释结果。 |
| `load_kechuang_potential_data.py` | 数据预处理模块：读取数据、重复检查/可选去重、日期筛选、一客多贷聚合、标签构造、泄露字段删除和特征工程。 |
| `sampling_methods.py` | 过采样、欠采样、组合采样和集成采样方法。 |

## 数据准备

将基础数据、违约终点状态和 LGD 字段按 `cst_id + loanacctno` 合并后，导出 CSV 或 Excel，随后在 notebook 的配置区设置：

```python
FILE_PATH = 'kechuang_base_risk_lgd_merged.csv'
TARGET = 'y_freq'       # 或 'y_dq_risk'
SNAPSHOT_DATE = '2026-06-24'
```

### 贷款账户重复处理

加载阶段始终输出 `(cst_id, loanacctno)` 的重复组合数、重复涉及行数、重复行数分布，以及重复组中“存在差异字段数”的分布。

```python
DEDUP_CST_LOAN = False
```

- `False`：不删除重复记录，仅输出统计；
- `True`：仅删除除键外所有字段都完全相同的重复行；同一键下存在字段冲突时立即报错，不会任意保留第一条。

关闭去重时，重复账户会参与客户级聚合，因此应先检查重复字段差异统计再决定是否开启。

开启到期日或起息日筛选后，如果源列缺失、边界配置颠倒，或者筛选后没有样本，程序会显式报错，避免在未应用预期口径时继续建模。

## 标签定义

### 频繁支用 `y_freq`

通过 `Y_FREQ_MODE` 选择口径：

| 模式 | 正样本定义 |
| --- | --- |
| `bout_gt0_and_curr_p80` | `ba_out_bal_diff > 0` 且 `ac_curr_bal_diff >= P80`。 |
| `bout_p80_and_accr_p80` | `ba_out_bal_diff` 和 `ac_accr_bal_diff` 均不低于 P80。 |
| `curr_p80_only` | `ac_curr_bal_diff >= P80`。 |
| `curr_p80_and_bout_p80` | `ac_curr_bal_diff` 和 `ba_out_bal_diff` 均不低于 P80。 |

计算 P80 和生成标签时，标签所需差额字段为空或非有限数值的客户会被排除，不会默认当作负样本。

### 违约风险 `y_dq_risk`

终点账户状态 `rt_acct_stat_2_end` 属于 `3、4、7、9` 时标签为 1，否则为 0。一客多贷时取最差终点状态；任一账户起点已为不良状态的客户会被剔除。终点状态缺失的客户也会被排除，不会默认当作未违约。标签及贷后表现字段不会进入模型特征。

## 数据划分与阈值

数据不再按开户时间顺序切分，而是通过三次分层随机抽样划分为四个互斥集合：

| 集合 | 比例 | 用途 |
| --- | ---: | --- |
| 训练集 | 60% | 训练候选模型；只有此集合可以采样。 |
| 模型选择验证集 | 15% | 候选方法的 AUC 与 Precision 取舍、早停。 |
| 概率校准集 | 15% | 在最终模型重训后确定固定分类阈值，不参与训练或方法选择。 |
| 最终测试集 | 10% | 方法确定后的最终评价。 |

每次切分均使用标签分层，因此各集合的正样本率尽量保持与总体一致。

不再配置 `KNOWN_POSITIVE_RATE` 或 `pi_k`。候选模型仍可在模型选择验证集上按验证集正样本率对应的概率分位数比较 Precision；最优方法确定并重训后，最终阈值只取概率校准集预测概率的：

```text
1 - 概率校准集实际正样本率
```

分位数。该固定阈值随后原样用于最终测试集，测试集标签不会参与阈值选择。测试集上另外输出的五档概率分位数 Precision/Recall 只作为 Top-K 覆盖诊断，不用于选择最终阈值。

所有会学习样本分布的特征预处理（数值和类别特征的高缺失删列、中位数/众数填充、类别编码词表）均只在 60% 训练集上拟合，再原样变换验证集、校准集和测试集；未在训练集出现的新类别编码为 `-1`。常见名义代码字段（如 `education_cd`、`busikind`）即使读入为数字，也会按类别而非连续值处理。

## 采样方法和模型选择

`sampling_methods.py` 支持：

- 过采样：`random_over`、`smote`、`borderline_smote`、`adasyn`；
- 欠采样：`random_under`、`tomek`、`enn`；
- 组合采样：`smoteenn`、`smotetomek`；
- 集成采样：`balance_cascade`、`easy_ensemble`（`ensemble` 是别名）。

候选方法仅在训练集采样与训练。先按模型选择验证集 AUC 取 Top 3，再比较各方法在验证集自动阈值下的 Precision；选定方法后以训练集和验证集合并重训，最终测试集不参与候选选择。

### 近邻缩放与混合特征

- `RobustScaler` 只在当前建模阶段传入的训练数据上拟合，并且只服务于 SMOTE、ENN、Tomek 等近邻距离；合成连续特征随后还原到原始尺度，LightGBM 仍接收原尺度特征。
- 类别列先 one-hot，再按 SMOTENC 的连续特征典型标准差加权；合成类别取种子的 `k` 个少数类近邻众数，并列时随机选择，因此不会产生小数类别编码。
- notebook 会在显式候选列表之外自动识别预处理器发现的名义类别列；`age` 保持连续变量，`档位` 保持有序数值，二者都不会按无序类别众数生成。
- 训练 LightGBM 时会把上述名义类别列显式传给 `categorical_feature`，避免把 LabelEncoder 编码误当成有大小关系的连续数值。
- `smote` 对应上述 SMOTENC 核心规则；`borderline_smote` 和 `adasyn` 是把同一混合距离/合法类别生成规则用于各自采样逻辑的扩展，并非库中原生的“SMOTENC-Borderline/ADASYN”类。

### Balance Cascade

当 `SAMPLING_ENSEMBLE_RATIO = 1.0` 时，每轮多数类子集与全部少数类等大。实现按论文设定目标假阳性率

```text
f = (少数类数 / 多数类数) ** (1 / (子模型数 - 1))
```

每轮用当前子集训练实际要进入最终集成的 LightGBM，再在剩余多数类池上调整本轮阈值，只保留目标比例 `f` 的难分样本进入后续轮次。`T` 个子模型之间只执行 `T-1` 次样本池转移，最后一轮训练完成后不再做无后续用途的淘汰；也不再用一个代理分类器预先生成全部子集。最终预测取各子模型概率的平均值。这保留了论文的级联采样与阈值日程，但把原论文每阶段的 AdaBoost 换成了项目统一使用的 LightGBM，属于 LightGBM 适配版而非逐字复刻版。

## 运行前仍需用业务数据确认

- `DEDUP_CST_LOAN=False` 时，重复贷款账户会重复参与余额差额和授信额度求和；开启后也只能自动删除完全相同的副本。冲突记录需先制定“保留哪条/如何合并”的业务规则。
- 客户聚合中的求和会保留“全部缺失”为空值；若同一客户只有部分账户缺失，现有值仍会被求和。是否应将这类“部分观测”客户整体排除，需要结合上游数据口径确认。
- 对应客户属性、科创评分和手机银行统计的 `mode/first` 聚合，程序会在聚合前报告“同一客户出现多个值”的字段及客户数。警告不能代替业务口径；若冲突较多，应先修复关联键或明确取值规则。
- 当前是客户级分层随机切分。若模型用于预测未来批次，建议另做按时间外推的 OOT 测试；随机切分不能验证时间漂移。
- `y_freq` 的 P80 是标签定义的一部分，当前按本次完整建模客户群计算。上线或跨期比较时应冻结业务阈值，或明确每期重算的口径，否则标签含义会随样本变化。
- 必须核对每个特征的观测时点早于标签表现窗口。代码会删除已知贷后/标签来源字段，但无法仅凭列名证明上游快照没有穿越。
- 同一模型选择验证集同时用于 LightGBM 早停和多种采样方法比较，结果可能有一定选择偏差；对高风险投产模型应补充重复分层交叉验证或独立模型选择集。

## 运行方式

安装依赖：

```bash
pip install numpy pandas scikit-learn lightgbm matplotlib seaborn shap openpyxl jupyter imbalanced-learn
```

打开并按顺序运行：

```bash
jupyter notebook kechuang_potential_preprocessing.ipynb
```

主要输出包括：样本与特征统计、采样方法选择表、最终测试指标及混淆矩阵、分位数 Precision/Recall、ROC/PR 曲线、累积增益图、Gain 特征重要性和 SHAP 图。与任务相关的表格、图和清洗数据文件名都带有 `_y_freq` 或 `_y_dq_risk` 后缀，避免切换任务运行时相互覆盖。
